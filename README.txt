ANGELO NAVARRA — INTERACTIVE WEBSITE DEMO

TO PREVIEW
  Option 1 (easiest): Open Angelo_Navarra_Interactive_Demo.html in any modern browser.
  Option 2 (editable source): Open index.html in this folder in any modern browser.

FEATURES
  - Real portrait of Angelo Navarra, softly cropped and optimized
  - Responsive desktop, tablet and phone design
  - Animated networking-themed hero and scroll effects
  - Clickable navigation and mobile hamburger menu
  - Skill-category filters (All, Networking, Hardware & Support, Soft Skills)
  - Capstone project details button and repository link
  - Experience, education, and clickable email/LinkedIn/GitHub
  - Reduced motion accessibility support

EDITING
  index.html — text, page sections, and links
  styles.css — colors, layout, and animation settings
  script.js  — interactive navigation, filters, and project details
  photo.webp — cutout of the provided portrait photograph

This is a standalone visual/interaction demo created to preview the requested design.
It does not replace the existing Next.js + TypeScript project automatically.
The standalone HTML preview has no npm dependencies.
The live website has not been deployed to a public URL.
